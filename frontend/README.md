# SmartHire Frontend

React frontend for the SmartHire AI-Powered Recruitment & Job Portal.

## Stack
- React
- Vite
- React Router
- Axios
- CSS

## Backend
The frontend expects the Spring Boot backend at:

http://localhost:8080

## Run
Open a terminal in this folder:

```bash
npm install
npm run dev
```

Then open:

http://localhost:5173

## Main roles
- JOB_SEEKER
- RECRUITER
- ADMIN

JWT is stored in localStorage after login and automatically sent with API requests.
